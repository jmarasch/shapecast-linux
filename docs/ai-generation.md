# Licence activation and real generation

Each user needs their own vendor-issued licence for the request code generated by this Linux installation. The helper preserves the original fingerprint hashing, signature validation, product checks and machine matching. It does not ship keys, borrow the maintainer's identity, or override the fingerprint to match a Windows/old request.

Before the commercial core imports its UUID helpers, the launcher selects a real permanent physical network adapter from Linux sysfs. It stores only the selector and its hashed identifier in the private installation and verifies them on each startup. It rejects synthetic/randomized addresses, virtual adapters and silent hardware changes. This fixes the changing identifier observed with the standalone Python runtime during development.

## A shorter request code is expected

The original core's Windows registry and macOS hardware-identifier lookups return no value on Linux. The Linux request therefore normally includes the product/version fields and the hash of one real physical MAC address, without fabricated Windows/macOS fields. It is shorter than a Windows/macOS request.

Ask Shapecast to issue a licence for this exact Linux request and explain that you are using an unofficial Linux compatibility helper. Vendor issuance is outside this project's control. A purchase alone does not make a key issued to another operating-system identity match this installation. If a previously issued key refers to an unstable or old request, ask the vendor to reissue it for the stable Linux request.

Launch the native profile and open **Linux setup**. Apply an emailed licence through the original core's activation endpoint. The online form also uses the original core's request fields; it may fail if the vendor endpoint is unavailable. The [official activation page](https://shapecast.io/pages/software-activation) is the manual alternative. Installation and doctor do not submit purchase information or activate automatically.

## After activation

Close the session, install native-use model files and the selected runtimes, then reopen. Model downloads/imports check the real local licence first. Jobs still pass through the commercial application's own licence enforcement; preview permissions are confined to the separate preview profile.

Native model generation has now been demonstrated on the maintainer's machine. The reusable helper does not include that machine's private migration records or request/licence contents. Fresh third-party licence issuance and a complete installation on another owner's hardware still need independent validation. See [validation](validation.md).
